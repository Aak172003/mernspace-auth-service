
Git hooks are scripts that run automatically every time a particular event occurs in a Git repository. 
They let you customize Git's internal behavior and trigger customizable actions at key points in the development life cycle.

Hoe install 
npm install --save-dev husky

The init command simplifies setting up husky in a project. It creates a pre-commit script in .husky/ and updates the prepare script in package.json. 
npx husky init
