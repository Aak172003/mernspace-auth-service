If we store access and refresh tokens in cookies, there is a risk they could be stolen.
To improve security, we refresh the access token by verifying the refresh token — which is stored both in the database and received from the client.

We save the refresh token in the database.
When a user logs out of the application, the refresh token is deleted from the database.
However, this alone is not 100% secure.

Token Rotation:
Each time we refresh the access token, we also generate a new refresh token.
This process continues until the refresh token reaches its expiry time.

This approach helps us maintain a higher level of security.
